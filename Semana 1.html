Semana 1 - Introducción a la Programación

En esta primera semana del curso se introdujeron los conceptos básicos de la programación, entendiendo cómo funciona la lógica detrás de los programas y el desarrollo web.

📌 Temas aprendidos

  • ¿Qué es la programación?
  • Lógica de programación
  • Algoritmos básicos
  • Pseudocódigo
  • Introducción a HTML

💡 Lo más importante

Se comprendió que la programación no solo es escribir código, sino resolver problemas de forma lógica paso a paso antes de implementarlos.

🧪 Actividad

Se realizó la creación de una página HTML básica con estructura: encabezado, párrafos y elementos simples.

🎯 Conclusión

Esta semana sirvió como base fundamental para entender cómo se construyen las páginas web y cómo pensar como desarrollador.
